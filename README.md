## 🛠 Selected open source

**Language & translation**
- [**readme_rosetta**](https://github.com/juleshenry/readme_rosetta): translates a README into many languages with local LLMs. `pip install readme-rosetta`
- [**mr.worldwide**](https://github.com/juleshenry/mr.worldwide): one word in, a gif of it in dozens of languages out (see above)
- [**polyglot-poster**](https://github.com/juleshenry/polyglot-poster): OCR a French textbook into a six-language wall poster
- [**jjokji**](https://github.com/juleshenry/jjokji): my language notes (FR/KO/PT/ES) and a CLI that turns them into Anki cards
- [**vulgultra**](https://github.com/juleshenry/vulgultra): a constructed language that runs Vulgar Latin in reverse, choosing among Romance forms with simulated annealing

**Science & ML**
- [**vakyume**](https://github.com/juleshenry/vakyume): an LLM-assisted pipeline that turns textbook equations into verified Python/C++ solvers with SymPy
- [**quantum-plankton-ml**](https://github.com/juleshenry/quantum-plankton-ml) and [**zooplankton-image-tool**](https://github.com/juleshenry/zooplankton-image-tool): classifying plankton with classical and quantum ML
- [**marionet**](https://github.com/juleshenry/marionet): full-body sign language (head, body, hands) compiled onto portable VRM avatars
- [**rafaga**](https://github.com/juleshenry/rafaga): VIX volatility models in Julia

**Tools & toys**
- [**superwand**](https://github.com/juleshenry/superwand): magic-wand selections that bring posterized and vector art to life. `pip install superwand`
- [**physical-menu-to-website**](https://github.com/juleshenry/physical-menu-to-website): photo of a menu in, restaurant website out
- [**tatuagem**](https://github.com/juleshenry/tatuagem): ASCII signature generator
- [**ghee**](https://github.com/juleshenry/ghee): shell shortcut manager
- [**intersekt**](https://github.com/juleshenry/intersekt): Karatsuba multiplication in WASM
